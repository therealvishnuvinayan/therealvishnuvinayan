# Artwork and font provenance

The layout, colors, neural graph, workflow illustration, chart code, project cards and profile artwork were created specifically for Vishnu Vinayan. No image, implementation code, statistic, ranking or personal branding was copied from the reference repository. Only its public README was reviewed to understand the full-width generated-image technique and responsive `<picture>` approach. There are no external logos, stock images, badge providers, tracking pixels or hosted statistics widgets.

IBM Plex Sans (Regular, SemiBold, Bold) and IBM Plex Mono (Regular) are distributed under the SIL Open Font License 1.1. Unmodified font files and their license are bundled in `assets/fonts/` to make rendering reproducible. Preserve the license with these files.

Upstream source: [IBM/plex](https://github.com/IBM/plex). Files were downloaded from:

- `packages/plex-sans/fonts/complete/ttf/IBMPlexSans-Regular.ttf`
- `packages/plex-sans/fonts/complete/ttf/IBMPlexSans-SemiBold.ttf`
- `packages/plex-sans/fonts/complete/ttf/IBMPlexSans-Bold.ttf`
- `packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf`
- `LICENSE.txt`

Font checksums are recorded in `assets/fonts/SHA256SUMS`. Dependencies are pinned in `package-lock.json`; their licenses remain with the respective packages. No license is imposed here on the owner's biography, project names, company material, or third-party code.
